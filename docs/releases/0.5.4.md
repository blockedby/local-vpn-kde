## Find every key in one window

The keyboard help and the command search were two separate windows, and the hint for them dropped off the bottom line on narrow terminals.

- **`?` opens «Клавиши»**, a single compact list: the current screen's actions first, then a «Общие» section. Select a row with `↑`/`↓` and press **Enter** to run it; confirmations still apply. Unavailable actions are greyed out, and the reason for the selected one appears on the bottom border.
- **Search:** `/` inside the window, or `:` / `Ctrl+P` from anywhere, searches the actions of every screen. The first `Esc` clears the search, the second closes the window. The old separate command window is gone.
- The bottom line always keeps **`? все клавиши`** on the right; other hints are dropped first when the terminal is narrow. The Servers screen also shows **`r обновить`**.
- The demo (`--demo`) now runs as the installed native app, with a demo subscription.
- The Docker runtime is no longer described in the README and the guides; it is not in use for now. Its code is unchanged.

**Upgrade:** `kvpn update`, then reopen `kvpn`. Only the interface changed, so the gateway does not need a restart.
