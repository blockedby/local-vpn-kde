## Breaking: the command is now only `kvpn`

The old `local-vpn-kde` command is gone. Packages install the launcher as `/usr/bin/kvpn`; `kvpn` with no arguments opens the interface, as before. Update shell aliases, scripts and desktop shortcuts that call `local-vpn-kde`.

Package, service, group, Polkit and directory names are unchanged (`local-vpn-kde-native`, `local-vpn-kde-users`, `/etc/local-vpn-kde`, …), so settings, profiles and enrollment carry over.

## Upgrading

- **From 0.4.5:** `kvpn update`, or **Settings → [u]** in the interface.
- **From 0.4.4:** `local-vpn-kde update`. After the update the old command no longer exists: start the interface with `kvpn`. If the interface was open during the update, it can't restart by itself; run `kvpn`.
- **Before 0.4.4:** install the package from this release by hand (`sudo pacman -U` or `sudo apt install` with the downloaded file).
