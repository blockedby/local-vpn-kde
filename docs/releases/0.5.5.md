## Settings and other menus work with arrows

Menu screens put a letter in front of every row, so they read as "press a letter", and changing a setting took a separate Enter.

- **Settings, Autostart, Diagnostics, Profiles, Recovery, Tasks and confirmation dialogs** now show `Title ..... value`. On/off and choice settings (Автостарт после сна, Режим, autostart options) show `‹ value ›`: `←`/`→` or `Space` change them immediately. Rows that open another screen end with `→`; `Enter` or `→` opens them.
- Letter shortcuts still work; they moved to a dim column on the right. The home tiles no longer show letters (choose a tile with the arrows; `?` lists every key), and the Servers screen without a table («Запустить сервис») uses the same row style.
- Dangerous actions (Остановить сервис, Перезапустить шлюз, profile removal) sit last, below a divider, and keep their confirmations.
- The bottom line follows the selected row: `←→ изменить`, `Enter открыть` or `Enter выполнить`.
- Lists stay compact on wide terminals.
- **Home screen:** the «Замеры» tile is gone (running checks still open the task list, `j` still opens it). The five tiles have centred titles and text, and the selected tile is marked by its border.
- README screenshots updated.

**Upgrade:** `kvpn update`, then reopen `kvpn`. Only the interface changed; the gateway does not need a restart.
