## Settings and other menus work with arrows

Menu screens put a letter in front of every row, so they read as "press a letter", and changing a setting took a separate Enter.

- **Settings, Autostart, Diagnostics, Profiles, Recovery, Tasks and confirmation dialogs** now show `Title ..... value`. On/off and choice settings (Автостарт после сна, Режим, autostart options) show `‹ value ›`: `←`/`→` or `Space` change them immediately. Rows that open another screen end with `→`; `Enter` or `→` opens them.
- Letter shortcuts still work but are no longer drawn on rows or tiles; `?` lists them. The home tiles no longer show letters (choose a tile with the arrows; `?` lists every key), and the Servers screen without a table («Запустить сервис») uses the same row style.
- Dangerous actions (Остановить сервис, Перезапустить шлюз, profile removal) sit last, below a divider, and keep their confirmations.
- The bottom line follows the selected row: `←→ изменить`, `Enter открыть` or `Enter выполнить`.
- Lists stay compact on wide terminals.
- **Home screen:** the «Замеры» tile is gone (running checks still open the task list, `j` still opens it). The five tiles are solid filled blocks with centred text (no box-drawing borders, which some terminals draw dashed); the selected tile is brighter.
- **Diagnostics:** the «Обновить диагностику» action comes first; the state follows as a compact two-column grid. **Profiles** starts right below the breadcrumb.
- **Server panel:** the row menu (Enter on a server) and «Подробности сервера» open as the same panel on the right, same size; the row menu no longer shows letters.
- Quieter status line: no «Список загружен.» after background list reads; clearer service start/stop messages; the Profiles hint moved to the status line.
- Fixes found while walking the menus: the Servers screen without a table runs the row you selected; editors always show their input at small sizes; searching no longer moves the selection in Settings; the server panel scrolls to every action and detail; recovery closes once the connection is back; `Esc` from «Задачи» returns to where you were; `↓`/`↑` on home go to the tile visually below/above; messages name actions instead of `[r]`-style letters.
- README screenshots updated.

**Upgrade:** `kvpn update`, then reopen `kvpn`. Only the interface changed; the gateway does not need a restart.
